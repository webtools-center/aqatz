## Какие сценарии для формы авторизации я бы еще проверил

1. Открытие страницы с формой авторизации (проверка факта доступности страницы).
2. Успешный вход (сабмит формы с правильными данными).
3. Проверка редиректа на защищенную страницу при успешной авторизации.
4. Проверка обработки спецсимволов, гигантских строк и других инъекций.
5. Проверка получения блокировки пользователя при превышении числа неудачных попыток входа.

## Быстрый запуск

```
git clone git@github.com:webtools-center/aqatz.git
cd aqatz
composer up
vendor/bin/codecept build
vendor/bin/codecept run
```
